🎙️ AI Video Senaristi (AI Video Scriptwriter)

Bu proje, Python ve Google Gemini API kullanılarak geliştirilmiş, içerik üreticileri için otomatik video senaryosu yazan yapay zeka destekli bir araçtır.

Özellikle YouTube Shorts, Instagram Reels ve TikTok için "Yüzsüz" (Faceless) içerik üretenlerin iş akışını hızlandırmak amacıyla tasarlanmıştır.

🚀 Özellikler

⚡ Hızlı Senaryo Üretimi: Konuyu girin, saniyeler içinde tam metni alın.

🤖 Hayalet Yazar Modu: Yapay zeka, doğrudan seslendirmeye uygun (okunacak) bir metin yazar. "Merhaba arkadaşlar" gibi gereksiz girişleri atlar.

🎬 Görsel Akış Planı: Videonun hangi saniyesinde ekranda ne görünmesi gerektiğini (stok video, oyun görüntüsü vb.) planlar.

🏷️ SEO Paketi: Viral olabilecek başlıklar, açıklama metni ve hashtag'leri otomatik üretir.

🎛️ Ton Ayarı: Ciddi, Enerjik, Gizemli veya Samimi tonlarda yazabilir.

🛠️ Kurulum

Projeyi kendi bilgisayarınızda çalıştırmak için şu adımları izleyin:

Depoyu İndirin:

git clone [https://github.com/KULLANICI_ADINIZ/ai-video-senaristi.git](https://github.com/KULLANICI_ADINIZ/ai-video-senaristi.git)
cd ai-video-senaristi


Gereksinimleri Yükleyin:

pip install -r requirements.txt


API Anahtarını Alın:

Bu proje Google'ın Gemini modelini kullanır.

Google AI Studio adresinden ücretsiz bir API anahtarı (API Key) alın.

API Anahtarını Ayarlayın:

app.py dosyasını açın.

GOOGLE_API_KEY = "BURAYA..." yazan yere kendi anahtarınızı yapıştırın.

▶️ Çalıştırma

Terminal veya komut satırına şu kodu yazın:

streamlit run app.py


Tarayıcınızda otomatik olarak uygulama açılacaktır.
